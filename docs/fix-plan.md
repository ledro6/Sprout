# План исправлений Sprout (задание владельца, фазы 2–7)

Полный текст задания владельца, кроме фаз 0–1 (они сделаны; см. `AUDIT.md`
и коммиты T-00…T-07). Аудит с файлами и строками — `AUDIT.md`.

## Решения владельца (окончательные)

- В саду настоящее время, демо-сада при первом запуске нет (сделано в фазе 1).
- Приёмка — тестами модели в `tool/swift-model-check` и сборкой на Mac CI.
  Симулятора нет, скриншоты и замеры владелец снимает на устройстве.
- Ветка `claude/sprout-fixes`, один коммит на задачу (`T-xx: …`), пуш после
  фазы.
- Удаление растения — с подтверждением, «Вернуть» держится 8 секунд (T-12).
- Расхождения с `CLAUDE.md` решаются по этому плану: «Итоги года» — по T-27.
- Аналитики в проекте нет. T-37 — только локальный журнал событий, если он
  дёшев; иначе задача пропускается с пометкой.
- Фото и вопросы к ИИ с телефона не уходят (Vision и FoundationModels на
  устройстве). Лист согласия из T-10 заменяется честной строкой «Разбирается
  на телефоне, ничего не отправляется», `PrivacyView` поправить по правде
  (WeatherKit и iCloud — описать, что уходит).
- Переводы на паузе: новые строки только по-русски, через
  `tool/make_strings.py`.

## Принципы

- Минимум действий: полить то, что просит воды, — 1 тап из любого места.
- Не навреди: путь к поливу влажной земли сначала предупреждает. Приложение
  не награждает за лишний полив.
- Одна правда: статус, срок и счётчики — из единого движка
  (`Model/Core/Status.swift`, `Model/Garden/Status+Plant.swift`,
  `Design/StatusStyle.swift`).
- Честная неопределённость: расчёт не выглядит измерением.
- Мягкий тон: никаких красных вспышек и обвинений.
- Цвет не единственный носитель смысла: цвет + значок + слово.
- Без сети работают полив и просмотр сада.

## Общие правила

- Изменение схемы данных — с умолчаниями при чтении старых файлов и тестом.
  Серии, награды и журнал не терять и не пересчитывать задним числом.
- Рискованные продуктовые изменения (серия, задания, ранжирование друзей,
  умолчания уведомлений) — за флагом, который можно быстро выключить.
- Строки — в каталоге, множественное число через plural-ключи и `Lang.format`.
- Светлая и тёмная тема; цвета только из токенов (`Model/Core/Legible.swift`,
  `Design/Tokens.swift`), тест контраста должен проходить.
- Не писать в интерфейсе утверждений, которых нет в коде.
- Обращение на «вы», повелительное наклонение для действий, без
  восклицательных знаков, кроме поздравлений. Приблизительное — «примерно»
  или «≈».
- Цели касания не меньше 44×44 pt. Системные текстовые стили.

## Фаза 2 — безопасность растений и данных

**T-08. Защита от перелива.** `wateringGuard` во всех путях полива: капля на
карточке, «Полить сейчас», свайп, «Полил» в уведомлении и виджете, «Полить по
очереди», массовый полив, «Уезжаю», Siri, часы, AR, планетарий, NFC.
При `warn(moisture)`:
- кнопка «Полить сейчас» становится вторичной (контурной), под ней «Земля ещё
  влажная (N %)»;
- нажатие открывает лист «Земля ещё влажная (N %)», текст «Лишний полив вреден
  корням», кнопки «Всё равно полить» и «Отмена»;
- без подтверждения полив не записывается;
- «лишний» полив не засчитывается в серию, задания, очки и «вовремя».

В массовых действиях растения в статусе wet и ok не участвуют. «Полил» в
уведомлении при wet не поливает, а открывает карточку растения. Тесты на все
точки входа: при 89 % без подтверждения записи нет, при 30 % — один тап без
листа.

**T-09. Серия, задания, награды — не стимулировать перелив** (за флагом).
- День «хороший», если на конец дня нет растений в urgent (и нет просроченных
  больше чем на день при расчётной влажности). Серия — хорошие дни подряд.
  «Заморозка»: один пропуск за 7 дней серию не обнуляет.
- Срыв: «Серия прервалась. Бывает — начнём заново», лучший результат виден, без
  красного.
- Задания: «Поливайте 5 дней за неделю» → «Ни одного пересохшего растения 7
  дней»; «Полейте вовремя N раз» — только поливы в окне soon/urgent; «до
  десяти утра» — только нужные поливы.
- Очки и уровни за поливы в wet/ok не начисляются.
- Миграция: накопленные серии и награды сохраняются, новые правила — с даты
  выхода.
- «До «Джунгли» осталось 2» → например «До «Джунглей»: 2 хороших дня».
- Приёмка: симуляция 30 дней «по нужде» против «каждый день» — первый получает
  не меньше очков и серии.

**T-10. ИИ: единый контекст, один вход, прозрачность.**
- «Что с ним?» и «Спросить сад» получают одинаковый контекст: вид, комната,
  влажность и её источник, последние 5 поливов, статус, дата последнего
  полива. В инструкцию модели: не советовать полив при wet/ok, при расчётной
  влажности — с оговоркой.
- Проверка ответа в приложении: если ответ советует полить при wet — первая
  рекомендация заменяется на «Сейчас земля влажная (N %): с поливом подождите»
  (или повторный запрос).
- На карточке растения один пункт «Спросить о растении» с двумя режимами («по
  фото», «вопросом»); на главной остаётся общий «Спросить сад».
- Процент уверенности → слова «Похоже на…», «Возможно…», «Не уверен» (если
  доля показывается — с подписью «уверенность»). То же в «Добавить».
- Прозрачность — по решению владельца (см. выше).
- Состояния: «Разбираю фото…» с отменой, ошибка «Не получилось. Попробовать
  ещё раз», пустой ответ, модель недоступна — понятное объяснение вместо
  исчезнувшего входа.
- Приёмка: фикстура «Баксик, 89 % (датчик), жёлтые листья» — оба режима не
  советуют полив; тест постобработки ответа.

**T-11. Общий сад: роли, подтверждения, дубли.**
- «Стереть сад» — только хозяину; у гостя пункта нет в иерархии вью. Гостю —
  только «Выйти из общего сада». Подтверждение: ввод числа растений («Введите
  18, чтобы стереть») или удержание 3 с; текст «Исчезнут все растения и весь
  журнал поливов — у всех, кто в общем саду. Вернуть их будет нельзя.»
- «Выйти из испытания», «Отправить счёт», «Пригласить» — в разные места,
  деструктивное не рядом.
- Недавний полив другим участником: на карточке и в строке «Полила Маша, N мин
  назад», кнопка полива приглушена; нажатие — лист «Маша уже полила N мин
  назад. Всё равно полить?».
- Дедупликация: два полива одного растения в пределах 10 минут (люди или
  датчик) — одна запись.
- Уведомление «Маша полила: …» без действий; настройка «Сообщать, когда полили
  другие» остаётся.
- Тест ролей (гость не может стереть ни через UI, ни через ссылку), тест
  дедупликации.

**T-12. Удаление растения.** Меню «•••» и долгое нажатие: подтверждение
«Удалить {имя}? Журнал поливов тоже исчезнет», «Удалить» (красная) и
«Отмена»; затем тост «Растение удалено · Вернуть» на 8 секунд; мягкое
удаление, окончательное стирание после окна. Рядом — «Растение погибло — в
архив» (T-30). «Вернуть» восстанавливает растение с историей.

**T-13. Датчик.**
- Текст без Xcode и HomeKit-ошибок: «Датчиков в «Доме» не найдено. Добавьте
  датчик в приложении «Дом» или выберите из списка выше».
- Одинаковые имена различать: «Рядом / Далеко» вместо дБм (дБм — в деталях),
  поле «Назвать»; «Мигнуть» — если API датчика это позволяет, иначе пропустить
  с пометкой.
- «Подключить датчик» — плашка на карточке растения без датчика (есть с T-07).
- Ручной и датчиковый полив в пределах 10 минут — одна запись (в обе
  стороны).
- Подключение с карточки ≤ 2 тапов.

## Фаза 3 — скорость основных сценариев

**T-14. Главная: блок «Сегодня» и «Полить всех».** Карточку дня (приветствие,
чипы серии, «Садовник / Задания недели») заменить компактным блоком ≤ 72 pt:
если `needsWater` не пуст — «Полить сегодня: n» и кнопка «Полить всех (n)»;
если пуст — «Всё в порядке · ближайший полив — {имя}, {когда}». Серия —
маленький чип справа. Садовник и задания переезжают в Профиль → Награды.
Приветствие — только в пустом саду. «Полить всех» поливает только
`needsWater`, тост «Политы n растений · Вернуть» на 8 с. Приёмка: первая
строка растения не ниже 250 pt на экране 874 pt, над сгибом ≥ 5 строк.

**T-15. Главная: сортировка, шапка, меню.** По умолчанию «Сначала сухие»
(внутри — по имени), выбор сохраняется, «Вручную» — вариант (у тех, кто уже
выбрал порядок, он сохраняется). Шапка: переключатель список/сетка и «•••»;
сортировка и шестерёнка уходят в «•••» (подменю «Сортировка», пункт
«Настройки»). Меню группами: «Сад» (Сад в AR, Спросить сад, Изменить
комнаты…) и «Уехать» (Уезжаю…, Полить по очереди). Подпись «Полить по
очереди»: «Показывает на экране блокировки, какое растение поливать
следующим». У всех иконок без текста — `accessibilityLabel`.

**T-16. Строки и карточки растений.** Список: миниатюра, имя, под ним статус
(значок + слово) и «полив через N дн / сегодня»; справа кольцо влажности с
числом и значком источника; круглая капля 44×44. Сетка: капля под фото, не
поверх; у срочной карточки кроме свечения — значок статуса. Тап по строке —
растение, по капле — полив (с T-08). В оттенках серого статус различим.

**T-17. Свайпы и контекстное меню.** Список: полный свайп вправо — «Полил» (с
T-08); влево — «Отложить на день» и «Настройки». VoiceOver — те же действия
как custom actions. Долгое нажатие: «Полить», «Настройки», «Посмотреть в
AR», «В другую комнату», «Удалить» (T-12).

**T-18. Лента комнат и правка.** Чипы по содержимому, горизонтальная
прокрутка; «+ Новая комната» — отдельная закреплённая кнопка справа; под
текущей комнатой «Сухих: n», если n > 0; обрезается только длинное название.
Невыбранные комнаты читаемы (контраст 4.5:1). Правка: ручки перетаскивания,
«−», альтернатива «Выше / Ниже» в меню для VoiceOver. Экран «Комнаты»: список
не уезжает под заголовок; секция «Дача» → «Какие комнаты на даче». Важно:
лента комнат с растущим заголовком (`RoomStrip`, README «Комнаты листаются»)
— авторская находка; менять её на чипы только если это не ломает листание
страниц комнат; если конфликтует — оставить ленту, выполнить остальные пункты
и описать в отчёте.

**T-19. Карточка растения.** Сверху вниз: шапка (назад, имя, «•••»); герой в
одну строку: миниатюра ≤ 96 pt, кольцо влажности, бейдж источника, «Полив
через N дн / Сегодня»; кнопка «Полить» (T-08); «Спросить о растении» (T-10) и
«В AR»; «Уход» с «Подкормил / Пересадил / Повернул»; график и «Записи»;
заметки; мета «вид · комната · добавлен» одной строкой. «Модель» — внутрь AR,
«Настройки» — в «•••» и в чип интервала «Раз в 9 дней ›» → лист со степпером
(−/+), «Обычно для вида: раз в 7 дней», «Применить рекомендацию». Колесо в
настройках растения → степпер. Токсичность — чип у имени со значком,
контраст ≥ 4.5. График: оси подписаны, X — даты. Приёмка: влажность, срок и
кнопка видны без прокрутки на 667 pt; смена интервала — 2 тапа.

**T-20. Добавление растения.** Вход: крупная «Снять» (accent.fill), вторичная
«Из фото», ссылка «Растение от друга»; вместо пустого квадрата — иллюстрация ≤
160 pt. После снимка — один экран без прокрутки: миниатюра; «Кличка»
(placeholder «Как назовём?», «Придумать» в поле; пусто → подставится
предложенное имя, ввод не обязателен); «Вид» («Похоже на монстеру ·
изменить», при низкой уверенности — три кандидата); «Комната» (текущая);
«Полив: раз в N дней» (по виду, «Обычно для вида…»); «Последний полив» (есть
с T-07); «Дополнительно» свёрнуто — 5 переключателей ухода по виду. «Посадить»
закреплена над панелью вкладок. После сохранения: тост «{Имя} посажен(а)» и,
если уведомлений нет, — «Напоминать, когда пора полить?» (T-26). Приёмка:
вкладка → «Снять» → затвор → «Посадить» — 4 тапа, без прокрутки и ввода.

**T-21. «Уезжаю».** «Полить тех, кому нужно перед отъездом (n)» — только
`needsWater`; подпись «Остальные (m) дождутся сами». После полива — пересчёт
и обновление списка соседу («Соседу ничего не нужно» или список с датами).
Откат — тост «Вернуть» 8 с. Возврат не раньше отъезда (подпись под полем,
кнопка выключена). Памятка соседу — по комнатам с датами; «сколько воды» —
только если есть в данных. Быстрое действие иконки «Уезжаю» (T-25).

**T-22. Поиск.** Пусто: «По запросу «{запрос}» ничего не найдено». Поиск по
всем комнатам, включая дачу. «Спросить сад» остаётся и передаёт запрос в чат.
Вход в поиск один (вкладка поиска iOS 26).

**T-23. Навигация и единообразие.** Шестерёнка — только в Профиле (и в «•••»
главной); убрать с Главной, Добавить, Поиска, Статистики. Кнопки «?» убрать:
подсказки при первом заходе, повторно — «Подсказки» в Профиле. Закрытие:
редакторы — «Отмена» слева и «Готово» справа; экраны для чтения (Сравнить
сады, Что с ним?, Спросить сад, Каталог, награды) — «Закрыть»; полноэкранные
истории («Итоги») — «×». Карточка «Хозяин» в Профиле → «Вы». В шапке любого
экрана ≤ 2 иконок.

## Фаза 4 — вне приложения

**T-24. Уведомления.** Одно утреннее на сад, по умолчанию 09:00 (время
настраивается): «Полить сегодня: {Имя1}, {Имя2} (+n)», действия «Полил всех»
(поливает только нужных, T-08) и «Завтра» (откладывает). Дача: «Вы на даче —
полить: n растений», действие «Полил». Остальной уход — не чаще одного
сводного в неделю; включено только то, что рекомендует вид; всего не больше 2
пушей в день. Тихие часы по умолчанию 22:00–08:00, настраиваются. Если долго
не открывают — реже, без вины. Умолчание «напоминания включены» — за флагом и
включается после первого растения (T-26). Приёмка: 18 растений и весь уход —
≤ 2 пушей в день; «Полил всех» работает без открытия приложения.

**T-25. Виджеты, App Intents, быстрые действия.** Виджет малый и средний: до 3
растений из `needsWater`, у каждого «Полил» (с проверкой T-08). Экран
блокировки: «Полить: n». Intents: «Полить {растение}», «Что сегодня
полить?». Быстрые действия иконки: «Полить всех (n)», «Добавить растение»,
«Уезжаю». Виджет обновляется после любого полива.

**T-26. Разрешения и знакомство.** Знакомство — 3 экрана вместо 7: что делает
приложение; как поливать (капля, свайп, виджет); уведомления — время и «Пока
без уведомлений». Остальное — подсказки при первом заходе. Разрешения — в
момент пользы, перед системным запросом — короткое «зачем»; уведомления —
после первого растения. При отказе — понятное состояние и «Открыть
Настройки» (камера, Bluetooth, HomeKit — тоже).

## Фаза 5 — статистика, эмоции, мягкие состояния

**T-27. Статистика.** Порядок по умолчанию: Сад сегодня → Ближайшие поливы →
Полив вовремя → Главное за период → Поливы → Когда вы поливаете → Комнаты →
Планетарий; остальное — по выбору («Выбрать» остаётся). «Итоги года» —
баннером вверху только с 1 декабря по 15 января; в другое время — внизу
списка и при ≥ 90 днях данных; метрики — только по нужным поливам. Полоса
влажности из сегментов → «Самые сухие» (5 строк: имя, статус, процент) +
«Показать все». «Заранее / Вовремя / В последний момент / Пересохло» → «Рано
/ В срок / Впритык / Пересохло»; цвета: Рано — wet, В срок — ok, Впритык —
urgent, Пересохло — тёмный urgent + значок. «Довольны» в кольце —
вторичным цветом.

**T-28. Друзья и сравнение.** Рейтинг и «Сравнить сады» — по «Вовремя, %», не
по числу поливов (оно справочное, без «победителя»). Подписи у чисел: «144
полива». Испытание запускает только пользователь, чужим не показывается по
умолчанию, выход — отдельный пункт «Выйти из испытания». Не подсвечивать
проигравшего; зелёная подсветка лучшего допустима. «Запросить обновление» —
если технически возможно.

**T-29. Отклик на полив.** Лёгкая хаптика и ≈ 400 мс анимация капли/кольца;
при «Уменьшить движение» — только смена состояния. Тост «Полито · Вернуть» — 8
с, над панелью вкладок. Звук не добавлять (существующие звуки, если они
выключаемые, — оставить по настройке). У всех путей полива в приложении.

**T-30. Пропущенный полив и «погибло».** Просрочено: «Просрочено n дн» тем же
статусом urgent + «Можно полить сейчас», без вспышек. «Растение погибло — в
архив»: лист «Бывает. Перенести в архив? Журнал сохранится», «В архив» / «Это
ошибка». Архив — раздел в Профиле; архивные не участвуют в `needsWater`,
«Сад сегодня» и сериях; серия из-за архива не обнуляется; «Вернуть из
архива». Поле архива — с умолчанием для старых файлов и в синхронизации
семьи.

## Фаза 6 — недостающие состояния

**T-31.** Реализовать (и превью SwiftUI в обеих темах):
- ИИ без модели/сети: «Для этого нужен интернет. Запись полива работает без
  сети.» — только если функция правда требует сети; для моделей на
  устройстве — «Apple Intelligence выключена или недоступна на этом
  устройстве» и что делать;
- полив без сети записывается локально (так и есть), у записей общего сада,
  ещё не отправленных в iCloud, — значок «ожидает отправки»;
- сбой синхронизации iCloud: плашка в «Профиль → Семья» «Сад не
  синхронизируется. Проверьте iCloud.» / «Подробнее»;
- камера запрещена: «Нужен доступ к камере, чтобы сфотографировать растение.»
  / «Открыть Настройки»; фото — аналогично;
- Bluetooth/HomeKit запрещены: «Нужен доступ к Bluetooth, чтобы найти
  датчик.» / «Открыть Настройки»;
- Face ID: «Не удалось распознать. Попробовать ещё раз» / «Ввести
  код-пароль»; блокировка — «Слишком много попыток. Введите код-пароль»;
- загрузка ИИ: «Разбираю фото…» / «Отмена»;
- общая ошибка: «Не получилось. Попробовать ещё раз»;
- пустой сад: «В саду пока пусто. Добавьте первое растение» / «Добавить» (и
  «Показать пример» из фазы 1);
- правка главной: «Перетащите, чтобы изменить порядок».

**T-32. Дача.** Две плашки дождя → одна «Дождь: полив отложен до {день}». Чипов
на даче ≤ 2. «Напоминать о дачных растениях только на даче»: без геопозиции
настройка выключается сама и показывается «Без геопозиции напоминания по даче
приходят как обычно».

**T-33. Данные и поддержка.** В Настройках: «Удалить все данные»
(подтверждение вводом слова; в общем саду — пояснение); «Экспортировать
журнал» (CSV и JSON через лист «Поделиться»); «Написать нам» (письмо с
версией приложения и iOS, без личных данных); ссылка на политику. Пояснение
про резервную копию оставить. Удаление стирает локальные данные и записи
CloudKit своего сада.

## Фаза 7 — тексты, доступность, производительность

**T-34. Терминология.** «Заранее / Вовремя / В последний момент» → «Рано / В
срок / Впритык»; «Довольны / Скоро пить / Ждут воды» → «В порядке / Скоро пить
/ Сухо»; «Хозяин» → «Вы»; заголовок «Сад сегодня» оставить, подпись «Состояние
сада»; «Планетарий», «Машина времени» — игровые, в конце статистики; «в
квартире» — убрать. Ни одно функциональное название не требует «Словарика»;
если в нём остались только игровые термины — убрать его с первого уровня в
«Подсказки».

**T-35. Доступность.** Dynamic Type до XXXL без обрезки; у каждой иконки
`accessibilityLabel`; кольцо влажности: «Влажность 89 процентов, измерено
датчиком, полив через 8 дней»; кнопка полива: «Полить {кличку}»; свайпы — как
custom actions. Кружки цвета в настройках — 44×44, не больше 8 в ряд; «Цвет
волны» — «Как узор / Свой цвет». Подпись «Узор на фоне» — по состоянию
переключателя. Учесть «Уменьшить прозрачность», «Уменьшить движение»,
«Повышенная контрастность».

**T-36. Производительность.** Список из 100 растений: ленивые контейнеры, кэш
миниатюр, без размытия на каждой строке; стекло — только на навигации, не на
каждой карточке.

**T-37. Измерение.** Аналитики нет — по решению владельца только локальный
журнал событий, если дёшев (без фото, имён и мест): water_tap (источник),
water_guard_shown/confirmed, water_all, add_plant_started/completed,
notification_action, permission_result, streak_broken. Иначе — пропуск.

## Что не менять

- Капля на карточке главной как основное действие (дополнить свайпом).
- «Подкормил / Пересадил / Повернул» в уходе.
- Откат полива «Вернуть».
- «Спросить сад» в пустом результате поиска.
- Три состояния геопозиции для дачи, роли хозяин/гость, подсказки на экранах.
- Цели 44×44 в шапке и панели вкладок, тёмная тема.
- Пять вкладок: Главная / Статистика / Добавить / Профиль и поиск.

## Готово, когда

- Нет пути, по которому влажную землю поливают без предупреждения.
- Статус, срок и счётчики везде из единого движка.
- Тест контраста проходит в обеих темах.
- Состояния T-31 реализованы.
- Mac CI собирает приложение, виджет и часы; гейт — GATE PASS.
