# Как Sprout попадёт к другим людям

Три ступени. Каждая следующая нужна, только если предыдущей не хватает.
Ступень 0 описана отдельно и подробно —
[нативная-на-телефон.md](нативная-на-телефон.md); здесь она для полноты
картины.

Главный факт, который определяет всё планирование: **iOS собирается
только на macOS.** Не потому что так удобнее, а потому что Xcode есть
только под Mac. Обходной путь — облачный macOS в CI, он в конце.

---

## Ступень 0. На своём телефоне

С обычным Apple ID, бесплатно: открыть `ios-native/Sprout.xcodeproj`,
выставить Team в **Signing & Capabilities**, выбрать свой iPhone, ⌘R. На
телефоне один раз довериться сертификату в **Настройки → Основные → VPN
и управление устройством**.

Ограничения бесплатной подписи, о которых стоит знать заранее:

- приложение живёт **7 дней**, потом нужно переустановить с Mac;
- одновременно не больше **3** своих приложений на телефоне;
- **10** идентификаторов приложения в неделю;
- push-уведомления не работают.

Для разработки этого хватает. Для «дать посмотреть другу» — уже нет:
чужой телефон так не подключить.

## Ступень 1. Тестировщикам — TestFlight

Требует **Apple Developer Program, $99 в год**. Другого способа поставить
приложение на чужой iPhone нет: у iOS нет аналога «просто отправить
файл», любая установка требует, чтобы устройство было либо в твоём
профиле разработчика, либо чтобы сборка шла через TestFlight.

Порядок:

1. Оплатить Developer Program, дождаться активации (обычно сутки).
2. В App Store Connect завести приложение с тем же bundle id, что стоит
   в Xcode — сейчас `com.ledro6.sprout`.
3. В Xcode: **Product → Archive**, потом **Distribute App → TestFlight**.
4. Пригласить тестировщиков по почте.

До 100 внутренних тестировщиков получают сборку сразу; внешних до 10 000,
но их сборку Apple коротко проверяет. Сборка живёт 90 дней.

## Ступень 2. App Store

Всё то же, что для TestFlight, плюс карточка приложения:

- скриншоты под каждый требуемый размер экрана;
- описание и ключевые слова;
- ссылка на политику конфиденциальности — обязательна;
- раздел **App Privacy**: какие данные собираешь. Sprout не собирает
  никаких, и это надо там честно указать — пустым его не оставить.

Иконка уже собирается из макета:

```bash
python3 tool/make_icons.py
```

Версия живёт в настройках таргета: `MARKETING_VERSION` — то, что видит
пользователь, `CURRENT_PROJECT_VERSION` — номер сборки, который **обязан
расти с каждой загрузкой**. Одинаковый номер стор отклонит.

Ревью обычно 1–3 дня. Частые причины отказа: приложение выглядит
недоделанным, есть неработающие кнопки, нет способа удалить аккаунт
(если есть регистрация), описание не совпадает с содержимым.

## Если Mac нет

iOS собирается в облаке. **GitHub Actions** с `runs-on: macos-latest` —
бесплатно для публичных репозиториев; для приватных macOS-минуты
тратятся быстрее обычных. Сертификаты и профили лежат в секретах CI,
сборка по пушу тега уходит в TestFlight. Настраивается один раз и дальше
не требует Mac вообще.

Платный аккаунт Apple всё равно нужен: облако решает вопрос железа, а не
подписи.

## Сводка

| Куда | Что нужно | Деньги | Сколько ждать |
|---|---|---|---|
| Свой iPhone | Mac + Xcode | — | 20 минут, живёт 7 дней |
| TestFlight | Apple Developer + Mac или CI | $99/год | день |
| App Store | всё выше + карточка | $99/год | дни + ревью 1–3 дня |

Цены и правила меняются — перед тем как платить, сверься с
[Apple Developer](https://developer.apple.com/programs/).
