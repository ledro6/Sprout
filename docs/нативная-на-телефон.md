# Нативная сборка на iPhone — по шагам

## Сначала главное: где лежит код

Код живёт **на GitHub**, а не в переписке и не «где-то в облаке». Чтобы
Xcode мог его собрать, файлы должны оказаться **на твоём Mac** — поэтому
терминал и ищет их локально, он прав.

Если терминал говорит «нет такого файла или каталога» про `ios-native` —
значит, копия на Mac старая: ты её забирал раньше, чем эта папка
появилась. Нужно не открыть проект, а сначала **обновить копию**.

---

## 1. Найти, куда клонировал

```bash
find ~ -maxdepth 4 -type d -name Sprout 2>/dev/null
```

Если что-то нашлось — переходи к шагу 2. Если ничего, значит копии нет,
и надо клонировать с нуля:

```bash
cd ~
git clone https://github.com/ledro6/Sprout.git
cd Sprout
git checkout claude/design-animation-mobile-deploy-3giior
```

Дальше сразу к шагу 3.

---

## 2. Обновить копию

```bash
cd ~/Sprout                # путь из шага 1
git fetch origin
git checkout claude/design-animation-mobile-deploy-3giior
git pull
```

**Если `git pull` ругается на локальные изменения** — примерно так:

```
error: Your local changes to the following files would be overwritten by merge:
        ios-native/Sprout.xcodeproj/project.pbxproj
```

Это Xcode дописал в файл проекта твою команду подписи. Она не нужна в
репозитории — у каждого она своя. Убрать и продолжить:

```bash
git restore ios-native/Sprout.xcodeproj/project.pbxproj
git pull
```

Если жалко выбрасывать — отложить вместо того, чтобы удалять:

```bash
git stash
git pull
```

---

## 3. Проверить, что файлы на месте

Это главная проверка. Не пропускай её: она за секунду отвечает на
вопрос «почему нет такого файла».

```bash
ls ios-native
```

Должно ответить:

```
README.md	Sprout		Sprout.xcodeproj
```

Если папки нет — значит, шаг 2 не отработал: ты либо в другом каталоге
(проверь `pwd`), либо не на той ветке (проверь `git branch --show-current`,
должно быть `claude/design-animation-mobile-deploy-3giior`).

---

## 4. Открыть проект

```bash
open ios-native/Sprout.xcodeproj
```

Команду надо запускать **из корня репозитория** — того каталога, где
лежат `ios-native`, `docs`, `README.md`. Если запустить из другого места,
терминал снова скажет, что файла нет.

Обрати внимание: здесь `.xcodeproj`, а не `.xcworkspace`. Workspace
нужен, когда сборкой заведует менеджер зависимостей; у Sprout
зависимостей нет вовсе — только системные фреймворки.

---

## 5. Подписать

Без подписи Xcode не поставит приложение на телефон. С обычным Apple ID
это бесплатно — платный аккаунт разработчика нужен только для TestFlight
и App Store.

1. Слева в навигаторе — верхняя строка **Sprout** с синей иконкой чертежа.
2. В разделе **TARGETS** выбрать **Sprout**.
3. Вкладка **Signing & Capabilities**, переключатель конфигураций на
   **All**.
4. Галочка **Automatically manage signing**.
5. **Team** — твоя `Имя Фамилия (Personal Team)`.

Если ругнётся `Failed to register bundle identifier` — поменяй **Bundle
Identifier** в этом же окне на своё, например `com.твояфамилия.sprout`.

---

## 6. Выбрать телефон и запустить

1. Подключить iPhone кабелем, разблокировать.
2. Вверху окна Xcode, справа от названия схемы `Sprout`, — список
   устройств. Выбрать там свой телефон (не симулятор).
3. Нажать **⌘R**.

Первая сборка — минуту-две.

При **первом** запуске телефон откажется открывать приложение и покажет
что-то про недоверенного разработчика. Лечится один раз:
**Настройки → Основные → VPN и управление устройством** → выбрать свой
Apple ID → **Доверять**. После этого снова ⌘R.

---

## 7. Чтобы работало с домашнего экрана

Отладочная сборка запускается только из Xcode. Это ограничение самой
iOS: отладочный код исполняется на лету, а такое разрешено только когда к
процессу подключён отладчик. Чтобы иконка работала сама:

**Product → Scheme → Edit Scheme…** (или ⌘<) → слева **Run** → поле
**Build Configuration** → выбрать **Release** → Close → ⌘R.

После этого можно отключить кабель, приложение запускается тапом по
иконке. Живёт 7 дней, потом ⌘R ещё раз.

## Если что-то пошло не так

| Что видишь | Что это значит | Что делать |
|---|---|---|
| `ios-native: No such file or directory` | копия на Mac старая или ты не в том каталоге | Шаги 2 и 3 |
| `pathspec 'claude/...' did not match` | ветка не скачана | `git fetch origin`, потом снова `checkout` |
| Xcode: «не удалось открыть проект» | файл проекта написан руками, где-то опечатка | `python3 tool/check_pbxproj.py ios-native/Sprout.xcodeproj/project.pbxproj`; если проверка молчит — проверка расскажет, где именно |
| `Signing for "Sprout" requires a development team` | не выставлена Team у **нового** проекта | Шаг 5 |
| Телефона нет в списке устройств | не разблокирован, не нажато «Доверять», или выключен режим разработчика | Разблокировать, подтвердить «Доверять» на экране телефона, включить **Настройки → Конфиденциальность и безопасность → Режим разработчика** |
| Ошибки компиляции в Swift | я писал этот код вслепую — Xcode здесь нет | Скопируй текст ошибки и пришли, поправлю |

Последняя строка не отговорка, а ожидаемый ход событий: у меня в этом
окружении нет macOS, я проверил синтаксис всех файлов и запустил модель,
но типы в экранах SwiftUI проверит только Xcode.
