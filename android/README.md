# Sprout для Android

Пробная одноразовая сборка: то же приложение, что на iPhone, написанное
заново на Kotlin, Jetpack Compose и Material 3. Оригинал — `ios-native/`,
его эта папка не трогает и дальше за ним не следует: новые правки идут
только в версию для iPhone.

Стекла здесь нет — вместо него всё родное для Android: плашки Material 3,
цвета обоев (Material You), системная заставка, жест «назад» с
предпросмотром, свой язык приложения, виджет, плитка в шторке, ярлыки на
значке.

## Поставить на телефон

Готовые APK собираются в `app/build/outputs/apk/release/`:

| Файл | Для чего |
| --- | --- |
| `app-arm64-v8a-release.apk` | почти любой телефон с 2017 года — **его и ставить** (~54 МБ) |
| `app-armeabi-v7a-release.apk` | старые 32-битные телефоны |
| `app-x86_64-release.apk` | эмулятор Android Studio на компьютере |
| `app-universal-release.apk` | всё сразу, если не знаете, какой нужен (~86 МБ) |

Скопировать APK на телефон, открыть и разрешить установку из этого
источника. Сборка подписана отладочным ключом Android: ставится на любой
телефон как есть, но для Google Play нужен свой ключ.

Нужен Android 8.0 или новее. AR — на телефонах с «Сервисами Google Play
для AR» (ARCore); на остальных кнопки «В AR» просто нет.

## Собрать

Нужны JDK 17+ и Android SDK с платформой 37 (`platforms;android-37.0`).
Путь к SDK — в `local.properties` (`sdk.dir=…`) или в `ANDROID_HOME`.

```bash
cd android
./gradlew assembleRelease            # APK — в app/build/outputs/apk/release/
./gradlew testDebugUnitTest          # все проверки
./gradlew recordRoborazziDebug       # проверки + снимки экранов в app/build/shots
./gradlew lintDebug                  # lint: 0 замечаний
```

Версии библиотек подобраны друг под друга (AGP 8.13, Compose BOM
2026.06, SceneView 4.37): Compose новее требует AGP 9.1, SceneView новее —
Compose новее. Обновлять — вместе.

## Что где лежит

```
android/
├── app/src/main/kotlin/com/ledro6/sprout/
│   ├── app/        процесс: один сад на всё приложение, уход в фон и возвращение
│   ├── model/      вся логика — перевод `ios-native/Sprout/Model` с Swift, без Android
│   ├── design/     тема Material 3, токены, узор фона, логотип, эффекты
│   ├── ui/         экраны на Compose — папка на раздел, как Features/ на iPhone
│   ├── platform/   Android: уведомления, виджет, плитка, замок, вибрация,
│   │               звук, датчик наклона, камера, строки, файлы
│   └── ar/         AR на ARCore + SceneView (Filament)
├── app/src/main/assets/models/   37 готовых моделей видов (GLB + описание)
├── app/src/main/res/             ресурсы; строки 48 языков собраны скриптом
├── strings/        строки, которых нет на iPhone (виджет, плитка, ярлыки, AR)
└── tool/           генераторы ресурсов
```

Правило то же, что на iPhone: экран знает о модели, модель об экранах —
нет. `model/` — чистый Kotlin (плюс состояние Compose), поэтому
проверяется на компьютере без эмулятора.

## Что чем заменено

| iPhone | Android |
| --- | --- |
| Liquid Glass, `.glassEffect` | плашки Material 3, тональные поверхности |
| панель вкладок `TabView` | `NavigationBar`; на планшете, раскрытом складном и телефоне боком — `NavigationRail` сбоку |
| цвета системы | свои цвета iPhone или цвета обоев (Material You, Android 12+) — переключатель в настройках |
| заставка | системная `SplashScreen` Android 12+ с логотипом из тех же кривых |
| Siri и «Быстрые команды» | ярлыки на значке (долгое нажатие) и плитка «Ждут воды» в шторке |
| виджет WidgetKit | виджет Glance трёх размеров с кнопкой «Полить» |
| уведомления с «Полил» | `WorkManager` + уведомление с кнопкой «Полил»; переживает перезагрузку |
| Face ID | `BiometricPrompt`: отпечаток, лицо или код телефона |
| Core Haptics | вибромотор: примитивы «щелчок»/«тик» на Android 11+, волна силы на старых |
| RealityKit, вода на Metal | ARCore + SceneView/Filament: те же модели, переведённые в GLB, те же расчёты вянущих и мокнущих листьев |
| Vision (что на фото) | ML Kit на телефоне, без сети |
| язык в настройках iOS | свой язык приложения — в настройках Android 13+ и в самом приложении |
| Dynamic Type | крупный шрифт: переносы по слогам, кнопки уходят под текст, даты мельчают, а не обрываются |

Всё прочее — экраны, узор, волна полива, тряска карточек, планетарий с
музыкой сфер, статистика, подсказки, тур, «Уезжаю» — повторяет iPhone.

## Строки

Переводы — те же таблицы, что у iPhone, в Android-ресурсах:

```bash
python3 tool/make_resources.py build    # tool/strings/*.json + strings/*.json → res/values-*/
python3 tool/make_resources.py check    # ключи кода, подстановки, формы числа: 0 замечаний
```

Ключ в коде — русская строка, как на iPhone: `Lang.text("Полив")`.
`strings/<язык>.json` — строки только для Android (виджет, плитка,
ярлыки, AR на ARCore) на всех 48 языках; `strings/overrides/` — где
перевод iPhone говорит «iPhone». Формы числа — по правилам Android
(ICU): где Android требует форму, которой нет в таблицах iOS (например,
`many` у чешского для дробных), она берётся из `other`.

## AR и модели

Модели видов — те же, что на iPhone (`Botany`, файлы Kit), переведённые
в glTF:

```bash
python3 tool/kit_to_glb.py build   # assets/models/*.glb + *.json, assets/previews/*.png
python3 tool/kit_to_glb.py check
```

В GLB каждая деталь — свой узел `piece-<n>` с позой из Kit; в `*.json`
рядом — роль материала (горшок, земля, лист, цветок) и поза детали.
Телефон двигает детали и красит материалы сам (провисание и желтизна от
сухости, тёмная мокрая земля, цвета «по фото»), теми же формулами, что
iPhone, — `model/Greenhouse.kt`.

Значки — Material Symbols: `python3 tool/fetch_icons.py`.

## Как проверено без телефона

- **Модель** — сад, поливы, отмена, время года, статистика, планетарий,
  подсказки, строки на всех языках: те же проверки, что у Swift-модели.
- **AR-расчёты** — поза каждой детали каждой из 37 моделей сверена с
  расчётом iPhone; все модели открываются, у каждой есть горшок, земля и
  листья.
- **Все экраны** (`ScreensTest`) — обход каждого экрана с настоящим
  рисованием (Robolectric, графика Android) в 8 раскладках: светлая и
  тёмная тема, русский, английский, арабский справа налево, немецкий с
  шрифтом ×1.6, маленький телефон на японском, планшет, телефон боком.
  Снимки — в `app/build/shots`, их смотрел человек.
- **Система** (`SystemTest`) — настоящими частями Android: запуск с
  заставкой и ярлыки (в том числе поверх открытого приложения), замок с
  отпечатком и без блокировки экрана, уведомление с «Полил», будильник
  напоминания, плитка, виджет всех трёх размеров — собранный в
  `RemoteViews` и разложенный. Уход в фон (замок, напоминания) проверен
  отдельным прогоном: в общем наборе часы процесса у Robolectric одни на
  все проверки.
- **lint** — 0 замечаний; осознанные исключения с причинами — в
  `app/lint.xml`.

## Что можно проверить только на телефоне

- **AR**: поиск пола, заслонение предметами, отрисовка Filament, вода из
  лейки, скорость на слабых телефонах. Расчёты проверены, картинку — нет.
- **Камера и ML Kit**: как угадывает растение на настоящих снимках.
- **Отпечаток и лицо**: само системное окно проверки.
- **Напоминания**: точность времени, когда телефон спит (режим Doze у
  разных производителей откладывает будильники по-разному).
- **Виджет** на настоящем рабочем столе: размеры клеток у лаунчеров разные.
- **Вибрация и звук**: как ощущается и звучит на конкретном телефоне.
- **Цвета обоев**: Material You на настоящих обоях.
