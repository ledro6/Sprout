# Sprout

Приложение-напоминалка о поливе комнатных растений. Экраны перенесены из
макета Figma «орпи», материал панелей — Liquid Glass в духе iOS 26,
написанный фрагментным шейдером.

Как выкатить это на телефон — отдельный документ: **[docs/на-телефон.md](docs/на-телефон.md)**.

## Запуск

```bash
flutter pub get
flutter run                 # на подключённом телефоне или эмуляторе
flutter test                # виджет-тесты, включая сверку с макетом
flutter analyze
```

Стекло рисуется только на Impeller — то есть на iOS и Android. На вебе
`ImageFilter.shader` недоступен, там включается запасной путь: размытие
с подкраской, без преломления. Интерфейс работает, но материал выглядит
обычным «матовым стеклом», поэтому судить о нём по браузеру нельзя.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `shaders/liquid_glass.frag` | сам материал: SDF формы → поле высот → нормаль → смещение выборки фона |
| `lib/glass/liquid_glass.dart` | виджет и параметры материала, запасной путь без шейдера |
| `lib/motion/springs.dart` | пружины в терминах SwiftUI: `Spring(duration:bounce:)` |
| `lib/design/tokens.dart` | цвета, шрифты, радиусы и отступы — из выгрузки Figma |
| `lib/design/pattern.dart` | фоновый узор и логотип, кривые взяты из макета |
| `lib/widgets/`, `lib/screens/` | интерфейс |
| `tool/figma_extract.py` | выгрузка макета из Figma REST API |
| `tool/glass_preview.py` | прогон шейдера в headless GL — проверять материал, не собирая приложение |
| `design/screens.json`, `design/tokens.json` | результат выгрузки, по нему сверяются тесты |

## Материал

Обычное матовое стекло — это размытие плюс полупрозрачная заливка, и на
стекло оно не похоже, потому что у настоящего стекла есть толщина. Здесь
она есть: из знакового поля расстояний (SDF) формы строится поле высот —
в центре линза толстая, к краю скруглённая, — из него берётся нормаль
поверхности, и по нормали смещается точка выборки фона. Отсюда преломление
на кромке: содержимое за стеклом у края «подтягивается» внутрь. Это и
отличает стекло от замыленного прямоугольника.

Два решения в этом материале стоит знать, прежде чем его править.

**Форму задаёт шейдер, а не обрезка вокруг виджета.** Поэтому и размытие
живёт внутри шейдера. Причина не в качестве: две формы умеют сливаться
через smooth-min, и перемычка между ними лежит вне обоих прямоугольников —
любой `ClipRRect` её бы срезал. Из-за этого же выборки размытия делаются
только там, где стекло есть: снаружи шейдер выходит раньше и отдаёт фон
нетронутым.

**Шейдер на каждую сборку создаётся заново.** Это не расточительность:
`ImageFilter.shader` сравнивается по идентичности объекта шейдера, а
`RenderBackdropFilter` при равенстве фильтра не помечает себя на
перерисовку. Переиспользовать один экземпляр и только менять униформы —
значит остановить анимацию.

Все длины передаются в логических пикселях. Размер текстуры выбирает
движок, поэтому шейдер сам считает масштаб из переданного логического
размера области — угадывать `devicePixelRatio` не нужно.

Униформы задаются по индексу, без имён. Лишний или забытый `setFloat`
сдвинет всё, что за ним, и материал сломается молча — поэтому их число
сверяется с самим `.frag` в тестах.

## Анимации

Движение везде пружинное, не по кривой Безье. Пружина умеет прерываться:
если дёрнуть элемент на середине анимации, он продолжит со своей текущей
скоростью, а не прыгнет. У кривой понятия скорости нет.

- **Меню комнат** вытекает из кнопки: один прямоугольник стекла меняет
  положение, размер и скругление от габаритов кнопки до габаритов панели,
  пункты проявляются друг за другом.
- **Подложка выбранного таба** переезжает пружиной и растягивается по её
  текущей скорости, а на месте собирается обратно.
- **Кнопка поиска**, раскрываясь, наезжает на таб-бар, и smooth-min тянет
  между капсулами перемычку — они стекаются в одну.
- **Нажатие на карточку** уводит её вглубь и сдвигает направление света,
  из-за чего блик проезжает по кромке.
- **Растение, которому пора пить**, дышит красным свечением. Выключается
  системным «уменьшением движения».
- **Экран растения** собирается по частям из прогресса самого перехода.

## Выгрузка макета

```bash
export FIGMA_TOKEN=figd_...        # токен нигде не сохраняется
python3 tool/figma_extract.py "<ссылка на файл Figma>" --out design
```

Кладёт в `design/`: `screens.json` (дерево слоёв с геометрией и стилями),
`tokens.json` (цвета, типографика, радиусы и тени, отранжированные по
частоте), `png/` (рендеры экранов) и `img/` (растровые заливки). Флаг
`--reuse-raw` разбирает уже скачанное дерево, не ходя в API.

## Проверка материала без телефона

```bash
python3 tool/glass_preview.py --out /tmp/glass.png --blur 20
python3 tool/glass_preview.py --out /tmp/merge.png --blur 14 --merge 40 --sep 100
```

Гоняет тот же `.frag` в headless GL на тестовом фоне, где преломление
видно сразу: сетка ломается на кромке, цветные пятна затекают под стекло.
Второй вызов показывает слияние двух форм.
