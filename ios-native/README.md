# Sprout — нативная версия под iPhone

SwiftUI, только iPhone, минимальная система — **iOS 26**. Стекло, его
анимации и нижняя панель здесь системные: ничего из этого в коде не
написано и писать не нужно.

## Собрать

Пошагово, от «код лежит на GitHub» до иконки на телефоне —
[../docs/нативная-на-телефон.md](../docs/нативная-на-телефон.md).
Коротко:

```bash
git pull                              # файлы должны оказаться на Mac
open ios-native/Sprout.xcodeproj      # из корня репозитория
```

Дальше как обычно: выбрать свой iPhone в списке устройств вверху,
проверить **Signing & Capabilities → Team** (см. [../docs/на-iphone.md](../docs/на-iphone.md),
шаг 3) и нажать ⌘R. Либо из терминала:

```bash
cd ios-native
xcodebuild -scheme Sprout -destination 'generic/platform=iOS' build
```

Приложение отладочное запускается только из Xcode — это ограничение iOS,
разобрано в [../docs/на-iphone.md](../docs/на-iphone.md). Чтобы работало
с домашнего экрана, собрать в Release (⌘< → Run → Build Configuration →
Release, либо `Product → Archive`).

### Что проверено без Mac

- синтаксис всех файлов — `swiftc -parse`, чисто;
- модель собрана и **запущена**: 20 проверок склонений, данных из макета,
  срочности полива и поиска. Она зависит только от Foundation, поэтому
  работает где угодно, где есть Swift:

  ```bash
  tool/check_model.sh
  ```

- `project.pbxproj` — ссылки и скобки сходятся (`tool/check_pbxproj.py`).

Экраны так проверить нельзя: SwiftUI существует только на платформах
Apple, и типы в них проверит только Xcode. Первая сборка может выдать
ошибки — присылай текст, поправлю.

### Если Xcode не открывает проект

`project.pbxproj` написан руками — Xcode на любую опечатку отвечает
одинаково невнятно. Проверка на месте:

```bash
python3 ../tool/check_pbxproj.py Sprout.xcodeproj/project.pbxproj
```

Если она молчит, а Xcode всё равно ругается — запасной путь на две
минуты: **File → New → Project → iOS App**, имя `Sprout`, интерфейс
SwiftUI, язык Swift; затем удалить из нового проекта сгенерированные
`ContentView.swift` и `SproutApp.swift` и перетащить в навигатор папку
`Sprout` отсюда. Xcode 16 и новее синхронизирует папки с диском, так что
файлы подхватятся сами.

## Время в саду

Влажность не хранится замороженной — сад её сушит. Раз в секунду
приложение отдаёт саду прошедшее время, и почва подсыхает ровно на
столько, сколько его прошло. Считаем от часов, а не от числа тактов:
пока приложение свёрнуто, таймер не идёт, а время идёт.

В жизни почва сохнет неделю, и на экране этого не разглядеть. Поэтому у
сада есть скорость времени — в профиле её видно и можно переключить.
По умолчанию секунда идёт за час: сутки проходят за 24 секунды, и видно,
как проценты убывают, а растения по очереди просят воды.

Сроки полива не хранятся отдельным числом, а считаются из влажности:
иначе после полива пришлось бы держать два согласованных числа, и рано
или поздно они разошлись бы. Скорость сушки у каждого растения своя и
подобрана так, чтобы начальные сроки сошлись с макетом — у Баксика 89%
и 9 суток сушки дают ровно те 8 дней, что нарисованы.

## Что делает система, а что мы

Системное, не написано ни строчки:

- **нижняя панель** — `TabView` с четырьмя `Tab` и `Tab(role: .search)`.
  Разделённые капсулы, стекло, перетекание подложки между вкладками,
  раскрытие поиска в поле, уезжание панели при прокрутке
  (`.tabBarMinimizeBehavior(.onScrollDown)`);
- **материал** — `.glassEffect(_:in:)`. Преломление на кромке, отклик на
  нажатие (`.interactive()`), подстройка под фон;
- **навигация** — `NavigationStack`: переход на экран растения, жест
  возврата свайпом, стеклянные капсулы кнопок в тулбаре;
- **слияние капсул** — `GlassEffectContainer` вместе с `glassEffectID`,
  если понадобится морфинг между стеклянными элементами.

Написано руками только то, чему нет системного аналога: узор фона,
белые растяжки поверх него, геометрия карточек и всплывающее меню комнат
(системное `Menu` рисует строки с разделителями, а в макете три отдельные
пилюли в стеклянной панели).

## Чего в макете нет

Экранов «Статистика», «Добавить» и «Профиль» в макете не нарисовано —
там только иконки вкладок. Вместо выдуманного интерфейса стоит честная
заглушка.
