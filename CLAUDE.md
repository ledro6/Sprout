# Правила работы в репозитории

- Отвечать по-русски. Работа — только над iOS-приложением (`ios-native/`);
  Android был разовым.
- Пуш — один раз, когда вся работа по запросу готова. По ходу — только
  локальные коммиты. Если в пуше нет кода приложения и проверок (только
  документация), в сообщение коммита — `[skip ci]`: минуты на Mac дорогие.
- Перед каждым коммитом — `tool/gate.sh`, в конце должно быть `GATE PASS`.
  Он идёт минут пять: запускать в фоне и ждать одним ожиданием, без опросов.
- WeatherKit и HomeKit в entitlements не включены нарочно — как включить,
  написано в README. Токен Figma — только в переменной `FIGMA_TOKEN`.

## Бережно к ресурсам, без потерь в качестве

Каждый шаг перечитывает весь разговор, поэтому дороже всего — число шагов
и размер того, что попадает в разговор:

- независимые вызовы — пачкой в одном ответе, несколько команд — одним
  скриптом;
- читать точечно: узкий `grep`, файл — нужным диапазоном строк, вывод
  команд — коротким (`tail`, `-q`, лимит строк); большие списки и файлы
  целиком не печатать, только что записанное не перечитывать;
- собирать модель и гонять гейт — раз на пачку правок, а не после каждой
  мелочи;
- новые строки переводить в конце серии, сразу в таблицы, без черновиков
  в размышлениях; несколько языков — одним слиянием;
- список задач — крупными пунктами, статусы — без обновления на каждый шаг.
